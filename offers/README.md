# 闲鱼 Agent 服务 · 货架与定价

三个场景 = 三个商品，但**不是同时推**。闲鱼是"比价 + 看评价"的地方，新手没有评价时高价 SKU 挂上去只会被划走。所以按"低价攒评价 → 主力走量 → 高客单承接"排。

## 为什么这样排

- **闲鱼 AI 服务卖家月均成交额不足 900 元**（平台侧统计口径），远程部署/安装的行情价是 100-200 元。指望闲鱼一个渠道撑 3000/月不现实，它只负责"低成本获客 + 攒评价"。
- **企业知识库在闲鱼成交率极低**：闲鱼买家 90% 是个人，愿意掏 2000 的公司采购根本不在这比价。所以闲鱼只放 199 诊断做钩子，正式交付靠小红书/知乎/本地商家群/朋友介绍。
- **带货视频流水线退货率最高**：产出质量依赖第三方模型和客户素材，客户预期是"能卖货"，达不到就退。先跟着主力款加购卖，别单独立项。
- 结论：**闲鱼负责前 5 单（199×5）和案例素材，第二个月起把精力挪到小红书，让客户来找你。**

## 合规红线（踩了直接下架，甚至封号）

1. **不卖"不可查询的虚拟服务"**。交付必须是可验收的实体动作：表、机器人、文档、录屏。所以每个 SKU 都写了"验收清单"，这不是客气，是合规要求——平台判退款时"服务无法验证"是买家的必胜理由。
2. **商品页不放二维码、手机号、微信号**。平台 OCR 识图 + 关键词检测，配图藏号是重点打击对象（2025 Q4 私域引流封号量同比 +47%）。
3. **不写这些词**：代运营、代发、刷、涨粉、包上热门、破解、代充、卡密、低价引流、加微信。全部换成"搭建 / 配置 / 对接 / 教学"。
4. **不承诺流量和佣金**。写"提升产出效率"，不写"帮你卖货"。承诺收益 = 虚假宣传，退一赔三的口子。
5. **不接需要资质的活**：医疗诊断、金融理财建议、教育升学承诺、爬取非公开数据。
6. **客户数据**：只要客户提供的文档/聊天记录，让他书面确认"有权使用"，我不做二次留存，交付后 30 天删本地副本。
7. **AI 产出要标注**。生成内容交付时说明"由 AI 辅助生成，发布前请自行审校"，被投诉未标注会限流。

## 身份与收款

- 无公司主体，只能个人收款。商品页写清：**"个人技术服务，可开发票请勿拍"**，省掉 80% 的扯皮。
- 单价超 1000 的单，走闲鱼"分阶段"：定金 50% 开工，验收后尾款。别一次收全款，也别一次不收。
- 不签"包效果"合同；要签就签"交付清单 + 验收标准"两页纸，我这边能出。

# 飞书多维表格结构（内容生产）

表名：`内容生产`。14 个字段，别多建——字段越多客户越不敢用。

| # | 字段名 | 类型 | 选项/说明 | 谁填 |
|---|---|---|---|---|
| 1 | 标题 | 文本 | 最终用的标题 | Agent |
| 2 | 商品/选题 | 文本 | 商品名或选题一句话 | 客户 |
| 3 | 卖点 | 多选 | 3-5 个短句，如"出差三天不用托人" | 客户 |
| 4 | 平台 | 单选 | 小红书 / 闲鱼 / 抖音 / 视频号 | 客户 |
| 5 | 角度 | 单选 | 痛点型 / 对比型 / 测评型 / 场景型 / 清单型 | Agent 预填 |
| 6 | 目标人群 | 文本 | 一句话，如"经常出差的养猫人" | 客户 |
| 7 | 状态 | 单选 | 待生成 / 生成中 / 待审 / 待发 / 已发 / 复盘 | Agent |
| 8 | 备选标题 | 文本（多行） | 3 条，换行分隔 | Agent |
| 9 | 正文 | 文本（多行） | 300 字内 | Agent |
| 10 | 标签 | 多选 | 5 个话题标签 | Agent |
| 11 | 封面 | 附件 | 1-3 张 3:4 | Agent |
| 12 | 计划发布 | 日期 | 排期落在哪天 | Agent |
| 13 | 发布链接 | 链接 | 发完回填 | 客户 |
| 14 | 数据 | 数字 | 赞/藏/评三个数字字段，或一个文本字段 | 客户 |

## 视图

1. **待办**：筛选 状态 ∈ {待审, 待发}，按 计划发布 升序 —— 客户每天只看这个
2. **日历**：按 计划发布 分组 —— 一眼看本周空档
3. **已发**：状态 = 已发，显示数据 —— 复盘用
4. **表格**：全字段 —— Agent 读写用

## 自动化（3 条，对应三个工作流）

| 触发 | 动作 | 产出 |
|---|---|---|
| 新增记录 且 状态=待生成 | 抓卖点 → 改写文案 → 出封面 → 状态改待审 | 字段 1/5/8/9/10/11 |
| 状态改为 待发 且 计划发布为空 | 排到下一个空档（平台配额：小红书 2/天） | 字段 12 |
| 计划发布 = 今天 且 状态≠已发 | 给客户发提醒（飞书机器人私聊） | 提醒卡片 |

## 建表注意

- 多选字段的选项用短句，别用长句（手机上显示不下，客户就弃用了）
- 「状态」是整条流水线的开关，一定要建单选，不要用文本
- 附件字段只收封面，正文里的配图另建字段，否则封面会被混进去

# 客户交付包（client-kit）

客户付完定金后，按这个顺序交付。**每完成一项打勾，最后一起过验收单。**

## 交付顺序

1. 建表：在客户自己的飞书空间建「内容生产」多维表格（字段见 `飞书表结构.md`）
2. 灌提示词：把 `prompts/` 里三份提示词逐个建成 Agent/自动化节点（或直接给客户手动用的版本）
3. 跑一条真实内容：当着客户的面走一遍"填 → 生成 → 排期"
4. 录屏 60 分钟配置过程，剪掉密码/密钥部分
5. 发 `使用手册.md`（改名成客户公司名）
6. 填 `验收单.md`，客户回"通过"截图存档
7. 第 14 天发"要不要月度维护"

## 交付目录

```
README.md            本文件（内部用，不给客户）
飞书表结构.md        字段 / 视图 / 自动化定义
prompts/             三份提示词（改客户行业词即可复用）
使用手册.md          给客户看的操作说明
验收单.md            逐项打勾，双方留档
```

## 不许做的

- 不把客户的内容表建在我的飞书里（数据归属不清，交付后扯皮）
- 不给客户我的 API key；key 在客户自己的账号下，或用一次性试用额度
- 不在交付里夹带"涨粉/播放量"承诺，一个字都不写
